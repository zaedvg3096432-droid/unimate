# Unimate

**Unimate** هو تطبيق Flutter لإدارة الروتين الأكاديمي، ويضم الجدول والمهام والملاحظات والعادات والحضور والنسخ الاحتياطي في واجهة ثنائية اللغة.

## الإصلاحات في الإصدار 1.0.1

تمت معالجة سبب عدم تبدّل اللغة بإزالة الاعتماد العملي على ملفات ARB غير المستخدمة وربط كل النصوص الرئيسية بطبقة ترجمة مباشرة تتبع `Locale` الحالية. عند اختيار العربية من صفحة **المزيد** يعاد بناء التطبيق فورًا، وتتبدل العناوين وشريط التنقل والحقول ورسائل الحفظ والجدول وشاشة البداية إلى العربية، مع تفعيل RTL من الجذر.

تم كذلك إصلاح الصفحات التي كانت فارغة أو غير موصولة. أصبحت المهام قابلة للإضافة والتعليم كمكتملة، والملاحظات قابلة للإنشاء والتثبيت، والعادات قابلة للتحديد، والمحاضرات قابلة للإضافة، وتسجيل الحضور يحفظ حالة اليوم، والبحث يعمل عبر المواد والمحاضرات والمهام والملاحظات. كما تمت إضافة تخزين دائم عبر `SharedPreferences` للحالة والإعدادات، واستعادة النسخة الاحتياطية أصبحت تشمل المواد والمحاضرات والمهام والملاحظات والعادات والحضور.

| المجال | الحالة الحالية |
| --- | --- |
| العربية والإنجليزية | تبديل فوري مع RTL/LTR وحفظ الاختيار بعد إغلاق التطبيق. |
| الجدول | عرض يومي وأسبوعي وشهري، تسجيل الحضور، تصدير PNG/PDF، وإضافة محاضرة. |
| المهام | إضافة وتحديد المهام، ترتيب غير المكتمل أولًا، وحفظ دائم. |
| الملاحظات | إنشاء ملاحظة، عرضها، وتثبيتها أو إلغاء تثبيتها. |
| العادات | عرض العادات وتحديد إنجاز اليوم مع حفظ الحالة. |
| الإعدادات | اللغة، الثيم، حجم الخط، التحفيز، وكتم الصوت أثناء المحاضرات. |
| البيانات | تصدير واستيراد JSON يشمل كل البيانات الأساسية. |
| البناء | `flutter analyze` وبناء APK Release ناجحان في GitHub Actions. |

## تثبيت APK

إذا كانت نسخة قديمة من Unimate مثبتة على الهاتف، احذفها أولًا ثم ثبّت APK الجديد؛ فالنسخة الجديدة مبنية بتوقيع Release مختلف عن النسخة السابقة. إذا منع Android التثبيت، فعّل إذن **السماح بالتثبيت من هذا المصدر** للتطبيق الذي فتحت منه الملف.

## التشغيل والبناء

يتطلب المشروع Flutter وDart المتوافقين مع `pubspec.yaml`:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

يعمل ملف `.github/workflows/build_apk.yml` عند الدفع إلى `main`، ويثبت Flutter وJava، ويشغّل التحليل، ثم يبني APK Release ويرفعه باسم `unimate-release-apk`. تمت إضافة توقيع تلقائي للنسخة الموزعة داخل بيئة البناء حتى لا تكون النتيجة APK غير قابلة للتثبيت.

> للتوزيع التجاري وتحديث التطبيق فوق النسخ السابقة، يجب لاحقًا استبدال مفتاح التوقيع المؤقت بمفتاح Release ثابت محفوظ في GitHub Secrets؛ أما النسخة المرفقة الآن فهي صالحة للتثبيت، وقد تحتاج إلى حذف أي نسخة سابقة بسبب اختلاف التوقيع.
